# Дальнейший путь B2 Quest

## 0.1 — первый работающий цикл

- [x] Карточка → вспоминание → самооценка → следующее повторение.
- [x] Урок → 3 вопроса → обратная связь → прогресс.
- [x] IPA, русская подсказка, системная озвучка.
- [x] Тематические подборки и локальное сохранение.
- [ ] Собрать APK и проверить на реальном Android: звук, системная кнопка «Назад», перезапуск, авиарежим, большой размер шрифта.

## 0.2 — сделать занятия надёжной привычкой

- Резервная копия и восстановление прогресса, безопасный перенос между устройствами.
- Диагностика стартовых знаний без обещания официального уровня CEFR.
- Расширение и редактура словаря; указание источника частотности.
- Дополнительные варианты тестов, задания с вводом ответа и колода ошибок.
- Прослушивание английского голоса до начала курса и помощь с офлайн-голосами.
- Необязательные напоминания с явным разрешением пользователя.

## 0.3 — слушать и отвечать

- Короткие аудиозадания «слушай и напиши».
- Shadowing (повторение за образцом): запись голоса после разрешения микрофона.
- Сравнение своей записи с образцом; не выдавать распознавание речи за точную оценку произношения.
- Сценарии аэропорта, аренды жилья, общения и собеседования.

## B1–B2 — отдельная большая работа

- Связные тексты, реальное аудирование, пересказ, аргументация и письменные ответы.
- Relative clauses, passive voice, conditionals, reported speech и другие темы в контексте.
- Проверка навыков отдельно: чтение, слушание, письмо и разговор.
- Опциональные AI-диалоги через собственный сервер; ключи API никогда не хранить в клиенте.
- Оценка стоимости, прозрачные правила обработки диалогов и возможность удалить их.

Игровая прокачка помогает практиковаться, но уровень B2 проверяется языковыми навыками, а не числом XP.
