# Проверка версии 0.1.0

Проверено в среде разработки 5 октября 2026 года.

## Автоматические проверки

- `npm run typecheck` — пройдено.
- `npm run lint` — пройдено.
- `npm test` — 6 тестов, 6 успешных.
- `npx expo-doctor` — 21 из 21 проверки успешны.
- `npx expo export --platform android --platform web` — Android Hermes-бандл и веб-бандл собраны.

Тесты логики: рост интервалов, сброс при забывании, приоритет просроченных карточек, исключение будущих повторений, ограничение очереди, начисление XP, защита от повторной награды за урок, серия по календарным дням, проверка повреждённого сохранения и целостности контента.

## Проверка интерфейса в Chromium

Проверялось само приложение на React Native Web, а не отдельный макет.

- Главный экран на 390 × 844; отсутствие горизонтального переполнения на 320 × 740.
- Открытие карточки, показ перевода, оценка памяти и переход к следующей.
- Перезагрузка страницы: XP и история повторения сохранились.
- Прохождение урока с 3/3; повторное прохождение с ошибкой и объяснением.
- Повторный урок не начисляет XP ещё раз.
- Поиск по русскому переводу, добавление в избранное и пустая выдача.
- Выключение русских подсказок и проверка следующей карточки.
- Обработка неизвестного идентификатора урока.
- Ошибок JavaScript во время этих сценариев не было.

## Что ещё нужно проверить на телефоне

Нативный APK не собирался; физический Android и эмулятор не использовались. Системная озвучка зависит от установленных голосов и требует проверки на конкретном телефоне. Также нужно проверить системную кнопку «Назад», безопасные отступы, увеличенный шрифт и сохранение после принудительного закрытия процесса.

Успешный экспорт Android-бандла не равнозначен успешной нативной сборке APK.
